# Importante

- **Inscripción:** Para poder ser incluido en las Actas de Trabajos
  Prácticos, en caso de aprobar los trabajos prácticos, es necesario haberse
  inscripto en la materia (a través del [Sistema de
  Inscripciones de la Facultad](http://inscripciones.exactas.uba.ar/exactas/)) y haber completado la encuesta de
  evaluación docente.
- **Régimen de aprobación:** La materia tiene dos parciales. Para
  aprobar los trabajos prácticos ambos exámenes deben ser aprobados con 4, en
  cuyo caso están habilitados para rendir el final. Sin embargo, si ambos
  parciales son aprobados y las notas suman mas que 13, promocionan la
  materia y quedan eximidos de rendir el final.\
  En caso de no aprobar un parcial, se proveen dos fechas de recuperación.
  El parcial a recuperar en cada fecha queda a discreción del alumno. En caso
  de tener que recuperar uno solo de los parciales, puede presentarse en las
  dos fechas a rendir, es decir, tiene dos oportunidades de aprobar. El
  recuperatorio no lleva nota, y solo determina si el alumno pasa a la
  instancia de final. No se puede promocionar si se llega a
  recuperatorio.
- **Normas de seguridad:** Se recuerda que es obligatoria la lectura
  de las [normas de higiene
  y seguridad](http://www.dm.uba.ar/varios/normseg.html).
